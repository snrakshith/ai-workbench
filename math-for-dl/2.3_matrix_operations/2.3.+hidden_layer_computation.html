Inside a Hidden Layer

How a neural network actually computes z = W·x + b

1
The Network

Every line is a weight. Every hidden neuron sums its incoming weighted inputs, adds a bias, and produces z.

2
What Each Neuron Computes
z₁
Hidden neuron 1 receives 3 weighted inputs + bias
// follow the 3 lines arriving at z₁
z₁ = (w₁₁·x₁) + (w₁₂·x₂) + (w₁₃·x₃) + b₁
z₁ = (0.2 × 1.0) + (0.4 × 2.0) + (0.6 × 3.0) + 0.1
z₁ = 0.2 + 0.8 + 1.8 + 0.1 = 2.9
z₂
Hidden neuron 2 receives the same 3 inputs with its own weights
// follow the 3 lines arriving at z₂
z₂ = (w₂₁·x₁) + (w₂₂·x₂) + (w₂₃·x₃) + b₂
z₂ = (0.5 × 1.0) + (0.1 × 2.0) + (0.3 × 3.0) + 0.2
z₂ = 0.5 + 0.2 + 0.9 + 0.2 = 1.8

The Same Thing in Matrix Form

Doing this neuron-by-neuron is slow. We pack all weights into one matrix W and compute every neuron at once.

Row 1 of W [0.2, 0.4, 0.6] dotted with x gives the input sum to neuron z₁ — exactly the same calculation we did neuron-by-neuron above.

Row 2 of W [0.5, 0.1, 0.3] dotted with x gives the input sum to neuron z₂.

→ Each row of W = one neuron's weights. Matrix multiplication does the dot product for every neuron in parallel.

x — input values
